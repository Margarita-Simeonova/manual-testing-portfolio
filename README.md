# Manual Testing Portfolio – Login Page

Manual testing of the login form on [Practice Test Automation](https://practicetestautomation.com/practice-test-login/): test design, test execution and bug reporting.

## What was tested

- Login with valid and invalid credentials
- Error messages for wrong username and wrong password
- Empty fields, case sensitivity, extra spaces
- Basic security checks (SQL injection, script injection, access without login)
- Log out, browser Back button, page refresh
- Cross-browser and mobile viewport (regression)
